# 阶段一操作指南

**状态：演示数据已填充，DeepSeek 已启用且四类真实调用成功；正式 V1/V2 效果评测待人工标签核对。全部业务数据为模拟数据。**

1. **打开应用。** 在项目根目录执行 `.\.venv\Scripts\python.exe scripts/start_local.py`，访问 http://127.0.0.1:5173 。若服务已运行直接访问；首次安装见 [README](../README.md)。登录 `staff`、`manager` 或 `admin`，口令在本机 `.env` 的 `DEMO_PASSWORD`。
2. **取号和接待。** 客户打开 `/take-number`，选类别领取号码。店员在“排队与窗口”叫号、开始接待；公共屏 `/public-board` 只显示票号等公开字段。过号、重排、取消和调整均保留记录，管理调整需要理由。
3. **查询和建议。** 本机当前可查询 `19900000003`，核对来源、时间、月费和已结束的合约。填写需求、预算和必保宽带，生成最多三项建议。一般样本可选择 89 元方案，月费差额 40 元，新合约 12 个月；具体以当次来源和政策为准。01 已用于成功办理，保留当时的 129/89 元快照。AI 按钮可选，手工处理路径始终可用。
4. **质检和办理。** 对所选方案质检，查看依据，填写人工复核原因。硬规则阻断必须修正；新需求或新方案需要重检。创建草稿后确认提交。只有“办理成功”表示 Mock 成功；“结果未知”点击“按原请求号核对”，不可换号重办。接待结束与受理结果分别记录。
5. **评价。** 结束接待后生成本次服务的专属评价链接，客户给 1—5 分并可填意见。链接有效 24 小时，一次服务只接收一份有效评价；未评价保持空值。评分与质检分开显示。
6. **复盘和管理。** 店长或管理员在“统计与改进”选择时间和类别、生成快照、查看分子分母及原记录。建议需审核并指定负责人、计划和目标；完成后记录前后样本、同期变化和验证结论才能关闭。没有改善也如实记录。

“文本质检”支持营销文案与客户答复的独立检查、驳回和修订；“资料管理”由管理员维护草稿并发布新版本；已发布版本不可覆盖。“提示词与运行”可查调用状态；“评测记录”只读展示已保存批次，离线计数不代表真实模型效果。

DeepSeek：当前已经使用你本地填写的密钥启用。更换配置时修改私有 `.env` 后重启主 API，不在页面、聊天或 Git 中填写密钥。恢复离线设为 `offline`。已有正常、未知、拒绝等完整示例，直接入口见 [演示数据记录](实施记录/phase1-demo-data.md)。

遇到未知费用先核查，不补零；模型失败走人工；外部未知按原号核对；断线查看最后更新时间。备份、恢复、受限重置及测试命令见 [README](../README.md)；本次验收和未验证项见 [施工记录](实施记录/phase1.md)。
