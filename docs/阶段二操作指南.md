## 新做一笔正常业务

1. 管理员在“资料管理”建实物商品，选择数量或序列号管理，新增并发布政策；每件固定优惠、适用区域和收款归类都在政策版本里维护。采购页面建供应商和采购单，由店长/管理员审核，仓库按实际数量收货；序列号商品必须逐台填写，不允许重复。
2. 在客户全景或接待记录进入销售，选择已发布政策和数量，生成订单后核对金额再确认。AI 草稿需人工采纳；最终金额仍由后端计算。套餐月费不计入本次收银，通信套餐须关联成功受理。
3. 选择模拟收款方式。成功后仓库确认出库。遇“到账后返回超时”，使用原订单的“按原付款号核对”；不要换单号再收一遍。拒付释放库存占用；未成功订单可取消，已成功款项不通过取消伪装退款。
4. 从成功订单或成功受理预约安装，填写地址和上海时间；店长派给 installer。装维按接单、领料、到场、安装、客户验收顺序记录。领料前可以改约并退回待派；不得绕过客户验收完成。
5. 已完成业务在“收益对账”生成收益记录，或在订单/工单中计入收益。使用当前有效的已发布规则冻结计算；重复点击返回原记录。账单以业务号和账期匹配；实际到账留空表示未知，填 0 才表示明确未到账。同一账期重复业务号拒绝再次导入，已有批次保留原始行。
6. 核清该收银员未决款项后生成日结，按实际现金填写交接金额，再由财务核对确认。不同支付方式、经营款、代收和押金分别列示。经营看板可按时间筛选并展开来源；改进任务仍需人工审核、记录执行和对照快照验证。

## GEO 文件格式

“经营与 GEO → 录入外部回答 → 批量导入采样文件”接受下列 JSON 数组，每批最多 100 条。真实采样只有在确实取得回答时才填 `simulated: false`；引用必须是 HTTP/HTTPS 网址。

```json
[
  {
    "platform": "模拟平台",
    "question": "本地安装需要什么准备？",
    "answer": "模拟营业厅提供预约咨询，价格以人工确认结果为准。",
    "brand": "模拟营业厅",
    "captured_at": "2026-10-03T10:00:00+08:00",
    "simulated": true,
    "citations": ["https://example.com/demo"],
    "factual_errors": "演示回答，不代表真实平台收录。"
  }
]
```
